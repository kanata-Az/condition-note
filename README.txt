コンディションノート Ver.3.0.0

GitHub / Cloudflare Pagesへそのままアップロードできる完全実装版です。

今回の更新：
- まとめ画面の「全体」「症状別」を新レイアウトへ更新
- 期間選択を1か月・3か月・6か月・1年・カスタムに対応
- 左右の矢印は選択中の期間単位で移動
- 表示期間をタップして開始月を選択可能
- カスタム期間テンプレートの追加・利用・削除に対応
- 症状別画面は期間内の最多症状を初期表示
- 症状一覧を「頭痛・めまい・耳鳴り・眠気・ムズムズ」に更新
- 「肩のムズムズ」は内部IDを維持したまま表示名だけ「ムズムズ」に変更
- 旧データの耳鳴り・眠気・ムズムズIDを自動移行
- appVersion / dataVersionを追加
- 移行前データを端末内に最大3件保存
- 保存キーは condition-note-v2 のまま維持し、同じURLでの更新時に既存記録を保持
- 手動バックアップ・復元機能を維持

重要：
同じCloudflare PagesのURLへ上書き更新してください。別URLで公開するとSafariの保存領域が別扱いになります。
念のため、更新前にバックアップJSONを保存してください。
