コンディションノート Ver.2.3 実装版

【今回の更新】
・全画面の共通ヘッダーを入力画面基準でコンパクトに統一
・カレンダーを7列の同一幅に固定
・日付内は症状アイコンを最大6枠表示し、7件以上は5個＋「＋」で表示
・カレンダー画面の症状一覧は最大8件を2行×4列で初期表示
・日付の詳細をモーダルではなくカレンダー下へ展開
・症状カードをタップすると該当症状の日だけをカレンダー上で絞り込み（再タップで解除）
・設定画面を症状の追加・編集・並び替え専用に変更
・その他設定を独立画面として実装
・テーマカラー、バックアップ、復元、テキスト出力を同じ画面内で操作
・テキスト出力は期間・症状・詳細・メモを指定可能
・出力履歴は最新5件まで表示し、6件目以降は履歴一覧画面へ移動
・履歴の再コピー・削除に対応
・PWAの開始URLとキャッシュ更新処理を安定化

【アップロード方法】
ZIPを展開し、中の6ファイルをGitHubリポジトリ直下へすべて上書きしてください。
Cloudflare Pagesのデプロイ完了後、Safariで公開URLを再読み込みしてください。
ホーム画面版が古い表示のままの場合は、一度ホーム画面アイコンを削除し、Safariから再追加してください。
