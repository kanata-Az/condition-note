コンディションノート Ver.2.3.1 実装版

Ver.2.1の実動アプリを基に、以下を実装しています。

・全画面の共通ヘッダーを入力画面基準でコンパクト化
・カレンダーを7列固定幅に変更
・日付マスの症状表示は最大6枠（7件以上は先頭5件＋「＋」）
・カレンダー下に症状カードを最大8件、2行×4列で表示
・選択日の詳細をカレンダー下に展開
・設定画面は症状管理専用
・その他設定を独立画面にし、テーマ、バックアップ、復元、テキスト出力を1画面で操作
・出力履歴は最新5件を表示し、6件目以降は履歴一覧へ
・古い画面が残りにくいようPWAキャッシュ更新処理を強化

GitHubにはZIP内の6ファイルをリポジトリ直下へ上書きアップロードしてください。
Cloudflare Pagesのデプロイ完了後、Safariまたはホーム画面アプリを一度終了して開き直してください。
その他設定の右上に「Ver.2.3.1」と表示されれば更新完了です。
