コンディションノート Ver.3.1.1

GitHub / Cloudflare Pagesへそのままアップロードできる完全実装版です。

今回の更新：
- 設定タイトルと同じ列の右端へ「その他設定」ボタンを移動
- 「編集」「並び替え」ボタンを小型化
- 症状一覧の縦間隔を詰め、件数が増えた場合は一覧内スクロールに対応
- 症状行の「>」表示を削除
- 症状追加フォームを症状一覧の最下部へ展開
- アイコンと名称を横並びに配置
- 絵文字選択をポップアップ表示し、「キーボードから入力」と「閉じる」を維持
- 並び替え時は左端の持ち手を押したまま上下へドラッグ可能
- 並び替えに「保存」「キャンセル」を追加し、保存前は既存順序を変更しない
- その他設定の表記を「バックアップを作成」「バックアップの復元」に統一
- バックアップ作成・復元の確認をポップアップ表示
- バックアップの初期ファイル名を CN_YYYYMMDD.json に短縮
- 復元完了後、画面更新の案内を表示して再読み込み
- appVersion 3.1.1 / dataVersion 4
- 保存キー condition-note-v2 を維持

同梱ファイル：
- condition-note-backup-merged-2026-08-04.json
  統合済み記録の保険用バックアップです。

重要：
同じCloudflare PagesのURLへ上書き更新してください。
既存のlocalStorage保存キーとデータ形式は維持しているため、Safari内の保存データをそのまま引き継ぎます。
更新前に現在のバックアップJSONも保存しておくと、より安全です。
