コンディションノート Ver.2.0 正式版

【主な機能】
・入力画面：カレンダー日付選択、前日／翌日、今日に戻る
・症状の複数選択、メモ
・症状ごとの追加情報
  - 数値（1〜10）
  - 左右
  - 高低
  - 左右＋高低
  - 単一選択（自由設定）
  - 複数選択（自由設定）
・カレンダー：1日最大6アイコン、日付詳細、編集への移動
・まとめ：症状割合、曜日別症状数、追加情報別集計
・設定：症状追加、編集、削除、並び替え
・絵文字一覧＋キーボード入力
・テーマカラー
・バックアップ／復元
・期間別テキスト出力と履歴
・Ver.1系のブラウザ保存データを自動移行できる場合があります
・PWA対応（ホーム画面追加、オフライン利用）

【使い方】
1. ZIPを解凍してください。
2. フォルダ内の index.html をSafariで開いて動作確認してください。
3. 継続利用する場合は、Webサーバーへ配置してSafariで開き、
   共有ボタン →「ホーム画面に追加」を選ぶとアプリ風に利用できます。
4. データはブラウザ内に保存されます。機種変更や再配置の前に、
   設定 →「バックアップ作成」を実行してください。

【重要】
iPhoneでは、ローカルファイルを直接開いた状態だとPWAやオフライン機能が
制限される場合があります。安定運用にはHTTPSで公開できる場所への配置が必要です。
