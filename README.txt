コンディションノート Ver.2.5.0

GitHub / Cloudflare Pagesへそのままアップロードできる完全実装版です。

今回の更新：
- まとめ画面を「全体」「症状別」の2画面構成へ変更
- 集計期間を1か月・3か月・6か月・1年・カスタムから選択可能
- 矢印で選択中の集計期間を前後へ移動可能
- 全体画面に集計期間、記録した症状数、最多症状、多かった曜日を表示
- 症状割合の円グラフと曜日別の症状数を横並びで表示
- 症状ごとの発生日数を最大8件のカードで表示
- 症状カードから症状別画面へ直接移動可能
- 症状別画面に発生日数、平均度合、最高度合、期間内割合を表示
- 症状別画面に度合分布、曜日別発生日数、月別推移、関連メモを表示
- iPhone 16で主要情報が1画面に収まりやすいコンパクト配置へ調整
- Ver.2.4.0のその他設定、バックアップ、復元、テキスト出力機能を維持
