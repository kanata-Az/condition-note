コンディションノート Ver.2.6.0

GitHub / Cloudflare Pagesへそのままアップロードできる完全実装版です。

今回の更新：
- 全画面のヘッダーとタブをコンパクト化
- 入力画面の詳細入力を症状ごとに1列で表示
- 頭痛は度合、耳鳴りは「左・両方・右・高音・低音」、肩のムズムズは左右を表示
- めまい・足痛・吐き気は詳細入力欄を表示しない
- 「吐き気・不調」を「吐き気」へ変更
- カレンダーの月表示と月送り操作をコンパクト化し「今月」ボタンを追加
- カレンダーの日付マスを全て同じ大きさに固定
- 日付を各マス左上へ固定
- 症状アイコンを日付の下に3列×2行、症状一覧の並び順で表示
- アイコンは最大6個、7個以上は先頭5個＋「＋」で表示
- 日付をタップすると、カレンダー下にその日の詳細とメモを表示
- 症状一覧は月内の発生日数を最大8件表示
- Ver.2.5.0までのまとめ画面・その他設定・バックアップ・復元・テキスト出力機能を維持
