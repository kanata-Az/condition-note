コンディションノート Ver.2.3 完全版

今回の反映内容

1. 全画面共通ヘッダーを入力画面基準のコンパクトサイズに統一
2. カレンダーを常に7列同幅で固定
3. カレンダー内の症状アイコンは最大6枠
   ・1〜6件：すべて表示
   ・7件以上：先頭5件＋「＋」表示
4. カレンダー画面
   ・月カレンダーと症状カード8件を1画面内に収まりやすく調整
   ・症状カードに当月の記録日数を表示
   ・症状カードをタップすると該当日の色を切り替え
   ・日付タップ時の詳細は同じ画面の下に展開
5. 設定画面は症状の追加・編集・削除・並び替え専用
6. その他設定を1画面完結型に再構成
   ・テーマカラーをその場で選択
   ・バックアップ作成と復元を画面内ボタンから実行
   ・期間、症状、詳細、メモを選んでテキスト作成・コピー
   ・テキスト作成ボタンまでiPhone 16の初期表示に収まりやすく調整
7. 出力履歴
   ・その他設定画面では最新5件のみ表示
   ・6件目以降は「すべての履歴を見る」から別画面へ移動
   ・再出力、履歴削除に対応
8. ホーム画面追加後も安定して起動するPWA設定を維持

アップロード方法
ZIPを展開し、以下のファイルをGitHubリポジトリのルートへ上書きしてください。
・index.html
・manifest.webmanifest
・sw.js
・icon-192.png
・icon-512.png
・README.txt

更新後はCloudflare Pagesの自動デプロイ完了を待ち、ホーム画面アプリを一度終了して開き直してください。
古い表示が残る場合はSafariで公開URLを再読み込みしてください。
